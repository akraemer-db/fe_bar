# Lessons

- **Value models: count only the assets that actually wear.** v1 counted 60 standby pumps at full pumping hours, which overstated the event base by 20%. Count active units, and treat standby as absorbing NPT.
- **Value lost time at margin, not revenue.** Exec buyers think in EBITDA, so lost spread hours are worth contribution margin x the share of events that actually stop the spread.
- **Any hero number must come out of the shared cost table.** v1's $55k came from nowhere. Each demo $ now traces to `mode_costs.csv`.
- **Look up the operating basis before assuming it.** 3,600 pumping hrs was a guess. Patterson-UTI and Liberty publish 21-22 pumping hrs per on-pad day.
- **Synthetic data calibrated to the value model is circular.** Say so in the deck. It proves the pipeline works, not the value.
- **POC criteria must be measurable within the POC.** A backtest can only validate lever 1 (failures caught). Levers 2-3 need a baseline now and measurement in the pilot.
